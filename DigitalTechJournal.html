Error 1 (18/8/26)

The first error I have encountered while building the foundations of my project is an importing issue with the Matplotlib library. When I try to run the scripts that use Matplotlib, a ModuleNotFoundError comes up saying, “No module named ‘matplotlib’”. To fix this problem, I had to install the Matplotlib module from the terminal using the command “python3 -m pip install matplotlib”. Though the issue did not fix immediately, after closing Visual Studio Code and reopening it, it looks like the file runs perfectly fine without the ModuleNotFoundError.

Error 2 (20/10/26)

My next error occurred while I was trying to integrate the moon into my simulation. Though I had the orbit animation for the Earth working perfectly fine, the addition of the moon has caused it to stop, and I realised that this is because I have not added the moon's constants into the other files that use the planet constants. After adding the moon's constants to the other files, I now get a ValueError which states, "setting an array element with a sequence. The requested array has an inhomogenous shape after 1 dimensions. The detected shape was (2,) + inhomogenous part." I found out that the error was caused by my code for the circular orbit velocity, which I made to return two values for the Earth and the Moon. This configuration caused the value error to appear because the velocity variable can only expect one value instead of two. For now, I have adjusted my velocity variable to take only the first value (the Earth) and ignore the second value (the Moon).

Today, I have just discovered that there is a Python library dedicated to creating orbital simulations called 'Orbital'. I saw that this library can produce much more accurate orbital plots with less coding, so I think it would be good to use for my project. After some time testing out the library, I have found it to be quite good. But while the still images of the planet orbits look good, actually animating the orbit to move around the planets is what will make it interesting. Animating the orbit in this library seems very simple as you just have to input "animate = true" on the line that creates the graph. However, The animation doesn't work even though its just one command. I kept trying to make it work but the orbit just won't move which is very frustrating. Implementing this library into my main project will improve the accuracy of the orbits, but if I can't get it working in time, then I'm not sure if it will be feasable to get it implemented before the due date.
